# FlowReader

FlowReader 是一个使用 Kotlin 和 Android Views 的 Android 朗读原型。

已加入会话阅读缓存与半屏提前采集：手动上下滚动不切换当前播放，已确认的新内容追加到队尾；向上浏览时不自动追赶视口。快照页可展开缓存及最近坐标，未确认内容不会直接合并。实现与边界见 [READING_SESSION_DESIGN.md](READING_SESSION_DESIGN.md)。

## 工程状态

已实现 Telegram、Reddit/X 可见节点采集；Reddit/X 使用专用正文提取规则，Telegram 暂用通用文本读取。系统 TTS、播放/暂停/继续、Reddit/X 跨屏自动续读已实现。无障碍服务启用后显示半透明白色悬浮球，单击展开上下自适应菜单，双击切换当前模式的播放/暂停；菜单提供四个对齐的独立图标：播放/暂停、朗读/纯滚屏模式、文本小窗、停止，间隙透明。球和图标为40dp，首页可修改配色；拖动松手吸边，闲置3秒自动缩为侧边圆角条，点击恢复，自动隐藏可在首页关闭。文本小窗默认隐藏，通过菜单按钮开启，右下角加粗边框可拖动调整大小；首页可重新开启被隐藏的悬浮球。

首页为设置页，提供无障碍设置入口、语速调节（默认1.5倍）、自动续读与X兼容模式（默认开启），偏好和小窗尺寸保存到本地。无障碍授权由系统设置管理。

语音引擎默认使用Edge在线合成，也可关闭在线引擎切回系统TTS。接口与Token预填，支持322种音色的搜索选择、自定义音色、连接测试、试听和系统TTS设置入口。在线合成会发送当前及预加载的下一段朗读文本到配置接口；单个合成任务串行执行并去重，播放同时预加载下一段。音频内存缓存上限16MB，停止/换正文/更换配置时取消并清除，暂停保留缓存且允许进行中的请求完成，不再继续预取。播放临时文件用后删除。默认接口需要联网，合成失败时提示原因，不会静默切换。

Reddit详情仅从帖子标题、帖子正文和评论正文容器提取，评论归属匹配包含作者和层级。自动续读失败时单独保留最近一次滚动前后快照、正文队列和原因；快照页可查看摘要，勾选原始节点可查看完整诊断。该现场仅存进程内存，清除快照或进程退出后消失，后续普通采集不会覆盖。调试读取入口为 `dumpsys activity com.flowreader --flowreader-continuation`。

Edge v2握手兼容代码参考 `rany2/edge-tts`，对应源码和许可证分别位于 `EdgeGecV2.kt`、`app/src/main/assets/licenses/edge-tts.txt`。

设置中的“语音预加载”可选关闭、提前1段、提前2段（默认1段），保存后下次播放生效；系统TTS不受该项影响。请求仍串行，音频总缓存上限16MB，空间不足优先淘汰更远的预加载段。快照页播放诊断显示当前服务实例累计的请求数、缓存命中数和当前缓存占用；停止会清除音频，计数保留到服务重建。

快照与诊断为独立页面，包含当前正文、采集信息、原始节点和清除按钮。只采集 Telegram、Reddit、X，最近8份快照仅保存在进程内存中。自动续读在匹配不确定或超时时停止并给出原因；Telegram 当前仅开放可见节点采集与通用文本朗读，专用正文过滤及自动续读尚未验证。

## 构建环境

- JDK 17
- Android SDK Platform 36
- Android Gradle Plugin 8.13.2
- Gradle 8.13
- Kotlin 2.3.10

准备好 JDK/SDK 和 Gradle Wrapper 后，在项目根目录运行 `./gradlew assembleDebug`。安装与启动验证需在授权调试的 Android 设备上进行。


模拟滚动测试：设置页开启“模拟播放（滚动测试）”及“自动续读”，每条等待时间可调100–5000ms（默认500ms）。在悬浮窗点击正文后静默推进高亮与真实半屏滚动；暂停、停止行为与普通播放相同。关闭模拟后恢复已选语音引擎。滚动动作及页面稳定等待不会加速。

朗读音频焦点按会话保持：暂停、合成等待和跨屏续读不主动释放，停止、切App、锁屏或系统抢占结束会话。
